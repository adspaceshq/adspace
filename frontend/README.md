# adspaces app

Next.js 16 (App Router), React Query and Tailwind. See the [root README](../README.md) for the overall
picture.

## Run

```sh
cp .env.example .env.local   # every variable is explained there
npm install
npm run dev                  # :3000, needs the API on NEXT_PUBLIC_API_URL
```

## How it fits together

- **No Solana calls from the browser.** All reads and transactions go through the API. No RPC URL
  belongs in a `NEXT_PUBLIC_` variable: those ship to every visitor.
- **Sign-in** is Privy (Google, X or email). The API turns Privy's token into a session cookie;
  `src/lib/session.tsx` exposes it. Privy loads only when someone signs in or was signed in before.
- **API client:** `src/lib/api/v2.ts` (browser) and `src/lib/api/server.ts` (server-rendered pages).
  Money arrives as strings of USDC base units; format it with `src/lib/money.ts`.
- **Layout:** `AppShell` gives guests an open layout and signed-in users the sidebar on every page.
  `fill` fits admin pages to one screen.
- **UI kit:** `src/components/ui/`. Colours, radii and type are tokens in `src/app/globals.css`; use
  them instead of raw values.
